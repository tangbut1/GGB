## 结果解读

### 终裁：中性，双方均被认定"统计越权"

裁判没有偏向任何一方，而是同时否定了双方的推论方式：

> 双方均犯统计越权：红方将 9 条稀疏样本升维为"数据原罪"与六层结构性崩盘，叙事密度掩盖证据真空；蓝方以 40% 置信度降解负面为噪音，却用历史基线高杠杆预言 V 型反转。事件性质未明，在缺乏第三方流量审计前，应回归事实核查而非叙事博弈。

行动建议：**暂停叙事博弈，要求第三方流量审计与官方网络模块开源，以事实核查替代情绪定性。**

双方最有力的论据（裁判原文摘录）：

- **红方**："未经告知"与"信任危机"确实击穿技术社区底线共识，且 FinBERT 将"偷传""后门"误判为积极，证明危机被算法系统性低估。
- **蓝方**：40% 置信度与 9 条低质量样本意味着负面标签更接近传播噪音，且在 Wireshark 级流量审计缺失前，将后端回传直接等同于恶意窃取属于有罪推定。

待验证项（watch_items）：

1. "偷偷上传"是恶意数据背叛还是技术语境误读（许可证校验 / 匿名遥测）
2. 危机将沿六层滑坡结构性崩盘，还是 72 小时内 V 型反转钝化
3. 本次仅采集到 9 条样本，比例类指标波动大，结论需更多样本复核

### 数据口径：为什么这些数字可以这样读

**信源分层（T1→T4）**：9 条样本中 3 条 T2 专业媒体（虎嗅网、华尔街见闻、财富号），6 条 T3 门户转载，无 T1 权威通讯社、无 T4 待核验来源。层级按域名后缀判定，不按搜索引擎给出的来源名字符串。

**情绪打分（SnowNLP 初判 + 大模型校正）**：SnowNLP 对中文财经/政治文本系统性低报负面，初判给出 负面 1 / 中性 0 / 正面 8；经 LLM 校正后为 **负面 8（88.9%）/ 中性 1（11.1%）/ 正面 0**，综合情感得分 −0.740。终裁与前端展示均以校正后结果为准。

**比例的统计不确定性**：负面占比 88.9% 的 Wilson 95% 置信区间为 [56.5%, 98.0%]——样本只有 9 条，区间很宽，这正是裁判要求"更多样本复核"的量化依据。

**风险分 45.7 的构成**（5 个实测维度加权，确定性计算，不随模型变化）：负面占比 88.9 × 0.35、权威缺口 66.7 × 0.15、关注度峰值 8.3 × 0.2、低可信占比 0 × 0.15、情绪悲观度 19.2 × 0.15。其中「权威缺口」= 无编辑把关样本（T3 + T4）占比，不含通讯社的话题不会被系统性判高。

**热词（jieba TF-IDF 实测权重）**：智谱 0.854（7/9 篇）、偷传 0.488（5/9）、ZCode 0.488（4/9）、代码 0.439（5/9）、AI 0.366（3/9）。

### 趋势：Prophet 外推，但数据质量评级"低"

Prophet 时序模型拟合 85 个观测点，外推 30 日热度演化，`data_quality = 低`、无降级（`fallback_reason` 为空）。界面同时给出确定性判据：后半段日均声量是前半段的 0.80 倍，方向为横盘。模型自带的建议为"市场情绪呈消极趋势，建议谨慎投资"——注意这是 Prophet 对情绪指数序列的外推，与终裁的"中性/横盘"是两套口径，界面「趋势」Tab 对两者都有明确标注。

### AI 洞察（ReportAgent 提取）

- **风险 · 用户信任流失**（置信度 0.85）：88.9% 负面舆情指向未经告知上传全量仓库，企业客户暂停采购风险极高。
- **机会 · 开源透明化契机**（0.65，反向观点）：智谱已致歉并开源软件，若借第三方审计重建开发者信任，危机可转化为信任资产。
- **异常 · 行业问题个体化**（0.55，反向观点）：Claude Code 同样被曝上传隐私，但舆情火力集中于 ZCode，存在竞品水军带节奏嫌疑。
- **盲区**：无法确认实际上传数据的范围与是否包含商业机密代码；无法量化企业客户流失比例；无法判断是否存在竞品恶意操纵舆情成分。
